# 店员/店长通知模板（上线前一天发送）

> 以下为中文与英文版本。**高棉语版本请由熟悉业务的母语同事翻译后再发**，不要直接机翻。
> 发送渠道：员工群 + 当面说明一次。上线时间、负责人联系方式请先填好。

## 中文

【Tea Cafe 后台升级通知】
各位好，我们将在 **{日期} {时间}** 升级后台系统，预计 **{X} 分钟**。期间员工群里的订单按钮可能暂时没有反应，请稍等，或直接在后台操作。顾客下单不受影响。

升级后有这些变化，请提前留意：
1. **后台菜单变了**：分成"运营、商品、财务、系统"四组；旧的"财务"拆成"每日报表"和"财务统计"。
2. **新建东西都在右上角**：商品、分类、优惠券、员工都是点页面右上角的"新增"，进入新页面填写；列表页不再有新建表单。
3. **订单页改成列表**：可以按订单号、顾客昵称搜索，按日期范围过滤（选 10-01 到 10-02 就包含这两天整天）；订单行里能直接打开顾客的 Telegram 聊天。
4. **缺货处理**：商品卖完时，在订单里点"标记缺货"，系统会通知顾客选择"去掉商品/更换/取消"；已付款订单只能"去掉商品"，差额会自动退（钱包部分立刻退回）。**有未处理缺货的订单不能接单、不能出餐**，请等顾客选择。
5. **待处理退款**：ABA 付款订单的退款需要**经理**转账后，在"待处理退款"页点"标记已转账"，并填写转账号。请每天清零。
6. **新员工第一次登录要改密码**：经理重置密码后，对方用临时密码登录会被要求改成自己的密码。

如果升级后遇到问题，请联系：**{负责人 / 电话 / Telegram}**。谢谢！

## English

**[Tea Cafe back-office upgrade]**
We will upgrade the back-office at **{date} {time}**, about **{X} minutes**. Order buttons in the staff group may not respond briefly — please wait or use the admin console. Customer ordering is not affected.

What changes:
1. **New admin menu** with four groups: Operations, Catalog, Finance, System. "Finance" is split into "Daily report" and "Finance stats".
2. **Create actions are at the top right** of each list (products, categories, coupons, staff). List pages no longer contain create forms.
3. **Orders is now a list**: search by order number or customer nickname; filter by date range (picking 10-01 to 10-02 includes both full days); open the customer's Telegram chat from the row.
4. **Out-of-stock handling**: mark the item in the order; the customer chooses remove / replace / cancel. Paid orders can only remove the item; the difference is refunded (wallet part immediately). **Orders with an unresolved shortage cannot be accepted or prepared** — wait for the customer's choice.
5. **Pending refunds**: ABA refunds are transferred manually by a **manager**, then marked done on the "Pending refunds" page with the transfer reference. Please clear it daily.
6. **First login after a password reset requires a new password.**

Questions after the upgrade: **{owner / phone / Telegram}**. Thank you!
