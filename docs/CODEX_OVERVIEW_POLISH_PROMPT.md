## 背景（我在真实页面上看到的问题）

页面在宽屏（约 2000px，卡片宽约 900px）下：

1. **图表缩在卡片中间，两侧大片留白，字很小。** 根因：各图表用固定 `viewBox="0 0 420 …"`，CSS 里 `.admin-chart { width:100%; height:180px }`，按高度等比缩放后居中，字号随之变小、变不可读。
2. **订单趋势、用户趋势没有坐标轴**：没有日期刻度、没有纵轴数值，只能看形状；图例字很小。
3. **时段分布**：24 根柱子没有小时刻度，看不出高峰在几点。
4. **热销商品**：商品名字体极小，几乎读不出；数值看不清。
5. **订单状态**：条形末尾数值被条形盖住一部分（如 "11"）。
6. **支付方式**：只有一种方式时是一整条粗条，信息量低。
7. **口径容易误解**：指标卡"待接单 29""待核验 19"是全部历史的待办；而"订单状态"图只统计所选 7/30 天，里面"新订单"只有 11，两个数对不上会被当成数据错误。
8. **页面标题重复**：顶栏一个"总览"，内容区又一个"总览"；"统计天数"下拉很小、不明显。

## 要求

### A. 让图表按真实宽度渲染（根治 1）
- 抽一个 `useChartWidth(ref)`（`ResizeObserver`），图表按**容器实际像素宽度**设置 `viewBox`/宽高（带合理最小/最大值），**字号在任何宽度下保持约 12–13px**，不再随容器缩放。窄屏（375）同样不溢出。
- 图表高度不再固定为方形比例：折线图 220–260px，条形图按条数计算（每条 ≥ 28px），不得出现大片空白。
- 不引入图表库，继续自绘 SVG，保留现有 `role="img"`、`aria-label`、`<title>` 与表格版可访问替代。

### B. 趋势图（订单趋势、用户趋势）
- **横轴**：日期刻度（7 天全部显示 `MM-DD`；30 天每隔 5 天显示一个），本地化日期格式；**纵轴**：3–5 条网格线 + 数值刻度，金额用币种小数位格式化（KHR 无小数）。
- 悬停/聚焦数据点显示 tooltip（日期 + 数值，两条曲线都显示）；键盘可聚焦。
- 两条曲线除颜色外要有区分（一条实线、一条虚线 + 不同数据点形状），图例字号 ≥ 12px 且靠近图表。
- 订单数与销售额量纲不同：用**双纵轴**（左订单数、右金额）或拆成上下两张小图，二选一，保证两条线都能看清。
- 数据全为 0 时显示"暂无数据"空状态，而不是一条平线。

### C. 时段分布
- 横轴小时刻度（每 3 小时标 `0 3 6 … 21`，窄屏每 6 小时），纵轴数值/网格线；高峰柱用强调色并在柱顶显示数值（只对前 3 高的时段标数值，避免拥挤）。
- 保留表格版，并补一行文字摘要，如"高峰时段：12:00–13:00（8 单）"（三语）。

### D. 热销商品
- 横向条形图：**左侧完整显示商品名**（过长省略并 `title` 显示全名，字号 ≥ 12px），右侧数值；条形长度按销量，图高随条数增长。
- 商品名取当前界面语言（有 `zh-CN`/`km` 名称用对应语言，缺失回退英文），不要全用英文名。需要的话在 `/api/v1/admin/dashboard` 的 `top_products` 里已有的 `name` 基础上，只在前端做语言选择；若后端只给了英文名，记录下来告诉我，不要擅自改接口。

### E. 订单状态 / 支付方式
- 订单状态：数值显示在条形**右侧外**（不被条形遮挡）；状态名用本地化文案；条形按状态流程顺序排列（新订单 → 已接单 → 制作中 → 可配送 → 已配送 → 已完成 → 已取消），0 值状态不显示或显示为空条但保持顺序一致。
- 支付方式：只有 1 种时不画整条粗条，改为"银行转账 17（100%）"的大数字 + 小图例；≥2 种时用堆叠条或环形图，图例含数量与百分比。

### F. 口径提示与指标卡
- 页头加"统计周期：近 7 天 / 近 30 天（门店时区）"小字，随 7/30 切换更新；"订单状态""支付方式""热销商品""时段分布"等图的标题旁显示同一周期标签。
- "待接单""待核验""待处理退款"三张卡加副标题"全部待办（不受统计周期限制）"（三语）。
- 去掉内容区重复的"总览"标题，只保留页头一个。
- "统计天数"改成醒目的分段切换（7 天 | 30 天），带当前选中态与键盘可用。

### G. 其他
- 深浅色都要可读：文字对比度 ≥ 4.5:1；网格线用低对比度；颜色之外要有文字/形状区分。
- 窄屏（375）：所有图表不溢出（`documentElement.scrollWidth <= clientWidth`），刻度自动稀疏化。
- 空数据、加载、错误三态保持。

2. **真实浏览器**（真实后端 + 种子数据，种子要有：近 7 天每天不同的订单与销售额、30 天以上数据、多种状态、≥2 种支付方式、≥10 个热销商品且商品名较长、至少一个只有英文名的商品）：

   - 断言：趋势图有横轴日期与纵轴刻度；字号不小于 12px（取渲染后 `getComputedStyle`/`getBBox` 校验）；图宽等于容器宽，左右无大片空白；热销商品名完整可读；375 无横向溢出；

   - 深色模式看一遍。
