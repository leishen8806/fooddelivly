# 财务统计口径

管理后台财务统计将订单销售、钱包扣款、充值和现金流入分开显示，避免重复计算。

## 字段定义

| 字段 | 计算方式 | 是否订单收入 | 是否现金流入 |
| --- | --- | ---: | ---: |
| 订单销售额 | 统计期间内未取消订单的订单总额 | 是 | 否（支付方式另行拆分） |
| ABA 订单收款 | 店员批准的付款凭证中的 `external_due_minor` | 否 | 是 |
| 钱包扣款 | `wallet.order_payments` 的支付净额（扣除退款） | 否 | 否（充值发生在此前或当日的另一笔资金流） |
| 充值入账 | `wallet.recharge_orders` 中已入账的 `received_amount` | 否 | 是 |
| 现金流入 | ABA 订单收款 + 充值入账 | 否 | 是 |

“已确认收款”旧字段仍保留为兼容字段，等于 ABA 订单收款 + 钱包扣款；后台新界面不再用它作为唯一收入指标。

## 示例

当天充值 100 美元、钱包消费 10 美元、订单销售额 1000 美元时：

- 订单销售额：1000 美元
- 钱包扣款：10 美元
- 若其余 990 美元通过 ABA 支付，ABA 订单收款：990 美元
- 充值入账：100 美元
- 现金流入：1090 美元（100 + 990）
- 充值后未消费余额增加：90 美元

不能把 100 美元充值再加到 1000 美元订单销售额，作为 1100 美元“订单收入”。其中 90 美元仍是用户钱包余额，10 美元是订单的内部扣款。
