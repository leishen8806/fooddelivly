## 任务

### 1. 总览页：把「订单状态」「支付方式」「热销商品」做成真正的图表，并给订单趋势加销售额
现状（我在真实后端上查过）：这三块只是文字列表，页面里只有订单趋势、用户趋势、时段分布三张 SVG。要求：
- **订单状态分布**：自绘 SVG 横向条形图或环形图（零依赖），各状态用不同颜色，**并带文字标签与数值**（不能只靠颜色）。
- **支付方式占比**：自绘 SVG 环形图或堆叠条，带图例与数值/百分比，支付方式名走 i18n（`MANUAL`→银行转账 等已有映射）。

- 所有图表保持：深浅色可读、三语、空数据/加载/错误三态、`aria-label` 与表格式可访问替代（`<table>` 或 `<desc>`）、窄屏（375）下不溢出、高度合理（不要方形）。
